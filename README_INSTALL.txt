HONEYSTASH SCHEDULER — INSTALL

1. Put every file in this folder at the ROOT of your GitHub repo
   (index.html, quick.html, hs-core.js, manifest.webmanifest,
    service-worker.js, .nojekyll, and the icons/ folder).
2. Commit + push. GitHub Pages will serve it.
3. On iPhone: open the Pages URL in Safari, then Share > Add to Home Screen.

DESKTOP  -> index.html  (full scheduler)
PHONE    -> quick.html  (fast day-by-day editing)
The phone page has a "Full view" link and the desktop has a "Phone view" link.

MOVING DATA BETWEEN DEVICES (no account):
  Desktop Sync tab -> Download backup -> AirDrop/iCloud to phone
  Phone/other device Sync... -> load the file. Done.
